# ¿Qué es Pandas?

Pandas es una librería de Python especializada en el análisis y manipulación de datos.

Permite trabajar con estructuras de datos organizadas de manera eficiente y sencilla.

Fue creada por **Wes McKinney** y es ampliamente utilizada en ciencia de datos, inteligencia artificial y análisis estadístico.

La librería se basa principalmente en dos estructuras:

- **Series** → estructuras unidimensionales.
- **DataFrame** → tablas de datos similares a hojas de cálculo.

---

# ¿Para qué sirve Pandas?

Pandas sirve para:

- Leer y escribir archivos de datos.
- Organizar información en tablas.
- Limpiar datos incorrectos o vacíos.
- Realizar cálculos y operaciones estadísticas.
- Analizar grandes volúmenes de información.
- Preparar datos para modelos de Inteligencia Artificial.

---

# Objetivo principal de la librería

El objetivo principal de Pandas es facilitar el análisis y procesamiento de datos de forma rápida, eficiente y sencilla utilizando Python.

# Principales funciones y características

## Características principales

- Manipulación eficiente de datos.
- Compatibilidad con archivos CSV, Excel y JSON.
- Manejo de datos faltantes.
- Filtrado y selección de información.
- Operaciones matemáticas y estadísticas.
- Integración con otras librerías como NumPy y Matplotlib.

## Funciones comunes

| Función | Descripción |
| --- | --- |
| `read_csv()` | Leer archivos CSV |
| `head()` | Mostrar primeras filas |
| `info()` | Información del DataFrame |
| `describe()` | Estadísticas básicas |
| `groupby()` | Agrupar datos |
| `sort_values()` | Ordenar datos |
| `dropna()` | Eliminar valores vacíos |
